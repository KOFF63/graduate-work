# Django Project with Autotests

![Tests](https://github.com/KOFF63/graduate-work/actions/workflows/tests.yml/badge.svg)

## 📋 Описание проекта

Django-приложение с набором автоматических тестов на Selenium WebDriver.

## 🛠️ Технологии

- Python 3.13
- Django 5.2
- Selenium WebDriver
- Pytest
- Allure
- Page Object Model

## 🧪 Тесты

**16 автотестов:**
- 6 тестов авторизации
- 7 тестов материалов
- 3 теста (старые)
