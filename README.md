# Django Project with Autotests

![Tests](https://github.com/KOFF63/graduate-work/actions/workflows/tests.yml/badge.svg)

## 📋 Описание проекта

Django-приложение (учебная платформа) с набором автоматических тестов на Selenium WebDriver.

## 🛠️ Технологии

- Python 3.13
- Django 5.2
- Selenium WebDriver
- Pytest
- Allure
- Page Object Model
- GitHub Actions (CI/CD)

## 🧪 Тесты

**16 автотестов:**

- ✅ Успешная регистрация
- ✅ Регистрация с дубликатом имени
- ✅ Успешный вход
- ✅ Неверный пароль
- ✅ Пустые поля входа
- ✅ Доступ к профилю

### Материалы (7 тестов)

- ✅ Приветствие для анонима
- ✅ Поиск требует авторизации

- ✅ Добавление только для админа
- ✅ Страница предмета требует логина
- ✅ 404 для несуществующего предмета
